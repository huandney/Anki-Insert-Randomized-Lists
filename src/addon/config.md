## Configuration for Insert Randomized Lists Add-on

**Important**: Please restart Anki to apply changes to these settings.

- `custom_style` (string): Custom CSS style applied to randomized lists in the editor fields. Example: `"border: 2px dotted gray;"`.
- `enable_custom_style` (boolean): Enable or disable the custom style for the editor fields. Default: `true`.
- `hotkey_toggle_list` (string): Hotkey for the "RL" button, which toggles a randomized list. Default: `"Alt+Shift+L"`.

**Note**: On some Linux setups, undoing (Ctrl+Z) right after creating a list with the `Alt+Shift+L` shortcut may leave the list behind. Clicking RL works normally; if this affects you, set `hotkey_toggle_list` to a combination without Alt, such as `Ctrl+Shift+Y`.
